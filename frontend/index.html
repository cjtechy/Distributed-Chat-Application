Got questions?

Frequently asked about the community hub

Who is this for?
Neighborhoods, clubs, teams, classes, congregations, and other small groups that already know each other and want one shared room.
Is it free to join?
Yes. Create an account on the community page and you’re in the same room as everyone else.
What if I miss a day?
History is saved. Scroll back when you return — nobody has to recap in private messages.
How many people can be in the room?
Up to 1,000 people in a room. That’s enough for a neighborhood, a club, or a large class without splitting into extra chats.
Where do I sign in?
Use Sign in or create an account. If you run the space, the admin portal is a separate sign-in.
